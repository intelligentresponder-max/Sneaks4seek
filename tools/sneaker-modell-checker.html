Tipp: ein Foto pro Merkmal (Sohle, Zungen-Etikett, Zehenbereich, Fersenbereich) — auf Foto tippen zum Vergrößern. Nichts wird hochgeladen, alles bleibt lokal im Browser.

🔍 Lens auf einem Foto öffnet das Android-Teilen-Menü — dort „Google"/„Lens" wählen für automatische Erkennung + Preisvergleich, genau wie beim manuellen Teilen aus der Galerie. Es gibt keine öffentliche Lens-API, deshalb läuft es immer über diesen Umweg, nie direkt in der Seite.

Modell automatisch erkennen

Schickt nur das gewählte Foto (verkleinert auf max. 1024 px) an die Werkstatt-API. Das Ergebnis ist ein Vorschlag – mit der Checkliste gegenprüfen, Felder bei Bedarf korrigieren und erst dann speichern (Drive-Ordner „Modelle“ + Sheet-Tab „Modelle“).

Style-Code nachschlagen

Steht auf dem Größenetikett innen am Schuh — zuverlässiger als jede Sichtprüfung, der Code identifiziert Modell und Colorway eindeutig. Enter drücken öffnet die Google-Suche in einem neuen Tab.

Beim Hersteller prüfen

Style-Code eintippen – das Format verrät meist schon die Marke.

Sucht den Code nur auf der offiziellen Hersteller-Domain. Taucht dort ein Produkt mit gleichem Code, Modell und Colorway auf, passt es. Kein Treffer heißt nicht automatisch Fake (ältere Releases verschwinden), ist aber ein Warnsignal.
Aktuelle Marktpreise gibt's nirgends kostenlos per API — die drei Knöpfe öffnen stattdessen direkt die Verkaufs-/Verkauft-Suche der jeweiligen Plattform mit dem Style-Code oben.
